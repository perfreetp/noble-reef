# 盆景造型台 · Bonsai Studio

一个树桩盆景造型编辑器：拖动骨架控制点弯曲树干，修剪枝条，自动铺设枝叶，
并用 manifold-3d 的实体布尔运算生成可挖空的盆钵，实时合成重心判断稳定倾向。

## 技术栈

- **TypeScript**（`strict`，无框架）
- **Web Components**：`<bonsai-card>` / `<bonsai-slider>` / `<bonsai-toggle>` / `<bonsai-chips>`，
  每个控件自带 Shadow DOM 与样式表，外观通过 CSS 自定义属性继承
- **three.js**：骨骼蒙皮式管道扫掠、实例化叶片、轨道相机
- **manifold-3d**：盆钵的挖空、圈足、排水孔、刻线、配重块布尔运算，运行在 Web Worker 中

## 模块

### 1. 骨架塑形（`src/core/skeleton.ts`, `src/core/pose.ts`）

- 程序化生成主干、一级枝、二级枝、细枝的骨架，共 **31 个可拖动控制点**
  （主干 7 个、每条一级枝 2 个、每条二级枝 1 个）。
- 拖拽控制点旋转它所在的那一节骨骼，旋转沿骨骼向下游**传播**：子枝、叶片、
  乃至下游所有关节都跟着父关节的新的姿态走。
- 按住 <kbd>Shift</kbd> 拖动同一控制点改为绕枝轴**扭转**。扭转角度沿该枝的一段
  关节平滑分摊，避免在单节上把树皮拧出折痕。
- 拖拽固定骨骼长度，所以拖动像「弯枝」而不是「拉长」。

### 2. 分枝修剪（`src/core/pose.ts` 的可见性表）

- 切换到「分枝修剪」，悬停时高亮被剪枝的**整棵子树**。
- 剪除后下游枝叶同步消失，木质量与叶质量立刻重算，重心指示随之移动。
- 左侧「分枝层级」列表可以随时恢复。

### 3. 枝叶生成（`src/core/foliage.ts`, `src/viewer/leafLayer.ts`）

- 叶片按骨架自动铺设，数量按分枝层级递减（一级枝 > 二级枝 > 细枝），
  同一叶团分成若干子簇，形成盆景特有的层叠叶盘。
- 叶片使用半透明材质；所有叶片在同一个 `InstancedMesh` 中，
  每次相机或姿态变化后**按深度从远到近重排**，避免密集处穿插变色。
- 叶片绑定在关节的绑定空间里，骨架一变形就跟着走，不需要重新生成。

### 4. 盆钵与重心（`src/core/potBuild.ts`, `src/workers/pot.worker.ts`）

- 盆钵全部是真实实体几何：旋转体/多边形外壁 → 挖空 → 圈足/盆脚 → 排水孔 →
  边缘刻线（莲瓣款为竖向花瓣浮雕）→ 可选钢质配重块。
- 主线程只发参数，布尔运算在 Worker 内完成，不阻塞拖动。
- 用闭合三角网格的四面体分解求出盆钵体积、质心与**支撑多边形**（最低一圈顶点的凸包）。
- 整树重心 = 木质 + 叶片 + 盆钵（含配重）的加权质心；
  重心投影到支撑面上，得到**支撑裕度**与**倾覆角**，判定稳定 / 临界 / 倾向倾覆。
- 拖动主干时重心球、垂线与地面环同步移动；「自动配重」会在盆底背面放钢块把合成重心拉回。

### 5. 性能

拖动主循环每帧只做：骨骼求值 → 管道重扫 → 叶片姿态 → 质量合成。
实测单帧 CPU 约 **1–4 ms**（约 940 片叶、117 个骨骼节点），远低于「单次拖动 200 ms」的要求。
叶片绑定数据与姿态无关，拖动时会缓存复用，只重算骨骼与叶片变换。
叶片排序与盆钵重建都已异步化，不会打断拖动。

## 数据与文件

- 编辑内容自动保存在浏览器 `localStorage`（500 ms 防抖），刷新后自动恢复。
  隐私模式下存储不可用时界面会提示，且不影响编辑。
- 「导出文件」生成一份 JSON，包含：
  - `skeleton`：全部骨骼节点与枝干层级、控制点列表
  - `shape`：弯曲四元数、扭转角、已剪枝干
  - `foliageData`：每片叶的锚点关节、偏移、朝向、大小、层级
  - `potData`：盆钵网格（顶点 / 法线 / 索引）、体积、质心、支撑多边形、质量
  - `stats`：叶片统计与稳定性读数
- 文件可拖入窗口或点「导入」载入，完整还原上述状态。
- 浏览器控制台里 `window.bonsai.app` 暴露了应用实例，便于调试。

## 目录

```
src/
  core/        # 纯逻辑：骨架、姿态、枝叶、盆钵几何、质量与稳定性
  viewer/      # three.js 渲染：管道、叶片实例、场景与交互
  ui/          # Web Components 与面板
  workers/     # manifold-3d 盆钵构建 Worker
  io/          # 工程文件的序列化与本地存储
  styles/      # 全局样式
  main.ts      # 应用装配
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 拖动浅蓝色控制点 | 弯曲该关节及其下游 |
| <kbd>Shift</kbd> + 拖动控制点 | 扭转 |
| 拖动空白处 / 滚轮 | 旋转视角 / 缩放 |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | 骨架塑形 / 分枝修剪 / 审视重心 |
| <kbd>F</kbd> | 重新取景 |
| <kbd>Esc</kbd> | 取消选中 |
