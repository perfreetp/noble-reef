# 酱汁流体摆盘渲染器

基于 TypeScript + React + three.js 的酱汁摆盘工具。浅色陶瓷盘面上以「粒子链 + 高度场」混合方式渲染酱汁,支持挤出、勾线、变换、灯光预设与 PNG 导出。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 类型检查 + 生产构建
```

## 功能

- **三种器型**:平盘 / 浅碗 / 斜口盘,均为程序化高度场;切换器型后已有酱汁自动贴合新盘面
- **挤出交互**:点击盘面开始挤出 → 按住拖动勾线(松开可续画)→ 双击或 Enter 收尾,Esc 取消
- **挤出头三档**:细 / 中 / 粗
- **粘稠度 0.2–2.0**:越高流动越慢(铺开动画更慢)、边缘越圆润(更多平滑迭代、截面更接近半圆)、表面越光滑高光越强(roughness/clearcoat 联动)
- **路径管理**:每条酱汁独立路径,可在右侧列表选中、删除;选中后可整体拖动(选择模式)、旋转、缩放
- **叠加遮挡**:按路径层序逐层抬升高度,由深度测试实现正确的叠放遮挡
- **灯光预设**:顶部柔光 / 侧逆光 / 暖色餐桌灯,切换即实时重算酱汁高光(PBR 材质 + 环境反射)
- **上限 24 条**:超出时自动替换最早的一条
- **导出 PNG**:包含盘面、酱汁与当前灯光
- **本地持久化**:所有摆盘数据存于 localStorage,刷新自动恢复

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键点击盘面 | 开始挤出(挤出模式) |
| 按住拖动 | 勾线 |
| 双击 / Enter | 收尾当前笔划 |
| Esc | 取消笔划 / 取消选中 |
| Delete | 删除选中路径 |
| 选择模式点击酱汁 | 选中并拖动 |
| 右键拖动 / 滚轮 | 旋转 / 缩放视角 |

## 结构

- `src/three/plates.ts` — 盘面高度场与盘体几何
- `src/three/sauce.ts` — 酱汁粒子链平滑、重采样、条带网格与 PBR 材质
- `src/three/SceneManager.ts` — 场景、灯光、交互状态机、流动动画、持久化、导出
- `src/App.tsx` — 顶部灯光栏、左侧材质面板、右侧路径列表
