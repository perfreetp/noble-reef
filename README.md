# 山地主题乐园 · 园区地形与步道布置工具

纯前端三维规划工具：笔刷塑造 256×256 地形 → 沿地形绘制带坡度校验的步道（自动生成护坡护栏）→ 放置自动整平地形的设施 → 设定沿步道漫游的相机关键点。支持最近 20 步撤销重做、数千实例植被、工程导出/导入。

## 技术栈

- TypeScript 5.9（strict）+ SolidJS 1.9（细粒度响应式）
- three.js 0.187（WebGL 渲染、InstancedMesh、自定义 shader 注入）
- Vite 7 构建，vitest 5 单元测试

## 四页工作流

顶部步骤条在四个页面间切换，单 canvas 常驻、场景不重建，只切换交互模式与侧边面板。

### 1. 地形编辑
- 抬升 / 压低 / 平滑三种笔刷，半径分小（6 格）、中（14 格）、大（28 格）三档，强度与平滑系数可调。
- 256×256 高度场（65,536 点），鼠标射线拾取地面，按住左键拖动连续作用；一次拖动记为一步历史。
- 实时等高线（等高距可调）与坡度色带着色（`onBeforeCompile` 注入 shader，保留 PBR 光照）；超 12° 坡度进入警示色带。
- 可重置为平坦地形或重新生成程序化分形山地。

### 2. 步道布置
- 单击地形添加控制点，拖动黄色控制球调整弯道（向心 Catmull-Rom 样条，自动地表吸附）。
- 按 2 m 等弧长采样，逐段检测坡度：超过 **12°** 的路段红色高亮，面板统计超限段数、长度与最大坡角。
- 自动生成路面、两侧贴地护坡（斜裙）与护栏（立柱 InstancedMesh + 双层横杆），可在面板开关并调整宽度/护栏高度。

### 3. 设施放置
- 设施库：观景台（圆形 r=12m）、缆车站（矩形 18×12m）、售卖亭（圆形 r=5m），均为程序化低模。
- 放置/移动时按占地整平地形：核心区完全平坦，外围 smoothstep blend 环保证 C0 连续无台阶。
- 整平区与步道相交时，路径控制点高度由地形派生、自动重算吸附与坡度标记。Delete 删除设施（地形不回填，可用撤销恢复）。

### 4. 视点漫游
- 沿步道里程 t 设定关键点（第一人称 / 俯瞰两种），可调每段时长。
- 播放时相机高度每帧重采地形、实时跟随起伏；第一人称沿切线观察，俯瞰为后置抬高俯角视角；支持播放/暂停/进度拖动。

## 横切能力

- **数据四类**：地形高度场、步道（控制点+样式）、设施实例、视点关键点，统一在 Solid store；植被只存 seed 与规则参数，实例确定性重算不入库。
- **撤销重做**：快照栈 + 切片结构共享，上限 20 步。地形切片捕获 TypedArray 引用（每次 stroke 前克隆，稳态约 5 MiB），其余切片 JSON 深拷贝；笔刷 stroke、控制点拖拽、设施整平都合并为单条历史。
- **植被性能**：树/灌木两个 InstancedMesh（目标 4000 实例，实测全场景约 35 次 draw call）。笔刷拖动中植被冻结只累积脏区，stroke 结束防抖 200 ms 做脏矩形增量重布；规则变更才全量重布。
- **导出/导入**：单个 `.json`，高度场为 base64 编码的裸 Float32 小端字节，带 `schemaVersion`；手写守卫校验（长度、有限数、枚举、引用完整性），悬空关键点丢弃并告警，预留版本迁移链。

## 架构边界

- 可序列化工程数据与轻量 UI 状态放 Solid 响应式 store；THREE.Scene/Mesh/Geometry、raycaster 等每帧变化的对象是引擎普通类字段，**不进响应式代理**。
- `Float32Array` 元素级变更无响应式通知，统一用 `terrain.revision` 自增驱动引擎派生重建（法线、路径吸附、植被）。
- 引擎 → store 只通过 `store/actions.ts` 中走历史栈的 action；store → 引擎通过 `createEffect` 订阅 revision/切片。

## 测试

纯算法层（不依赖 WebGL/DOM）由 vitest 覆盖：数学插值、高度场坐标与法线、笔刷核与平滑、整平 blend、Catmull-Rom 采样与 12° 坡度判定、植被确定性散布与脏区增量、历史栈上限与结构共享、base64 往返、DTO 校验、漫游时间线，以及 store 全链路 action 集成（含设施整平→路径联动的复合命令）。
