# GRIND · 滑板场地几何建模

浏览器里的滑板场地建模工具：从元素库放置坡道、台阶、栏杆，用 **manifold-3d** 的布尔运算把交叠的实体缝合成流形正确的场地模型，再用 **three.js** 实时预览、检查碰撞网格并导出分享。

```
npm install
npm run dev        # http://127.0.0.1:5174
npm test           # 几何 / 文档模型的单元测试（Node，无需浏览器）
npm run test:e2e   # 端到端测试（需要 npm run dev 已在运行）
npm run build      # 生产构建到 dist/
```

## 功能

**元素库** — 9 种参数化元素，分三组：

| 分类 | 元素 | 参数 |
| --- | --- | --- |
| 坡道 | 斜面坡、弧形跳台、四分之一管、波浪坡 | 宽 / 长 / 高 / 半径 / 弧面指数 / 平台 |
| 台阶与台子 | 台阶、台子、金字塔台、方箱 | 宽 / 长 / 高 / 级数 / 级高 / 级深 |
| 栏杆 | 圆形钢管栏杆 | 长度 / 高度 / 管径 |

每个元素在放置后都能用检查器实时改参数，几何在 Web Worker 里重建，不阻塞交互。

**布尔合并** — `manifold-3d` 在 Web Worker 中运行：

- **并集**：把一个元素并入已有的合并组，或把多个元素合成新组。交叠部分被缝合，内部面消失。
- **差集**：把切割体从实体中减去，可以做碗池、开孔、切口。
- 每次合并后自动用 `calculateNormals` 重算法线，并提取新的轮廓线。
- 结果始终被校验为闭合二维流形（`status() === 'NoError'`），面板显示三角面数、体积、亏格。
- **稳定性**：模型永远从元素参数重建，从不基于上一次的布尔结果；连续 25 次以上合并后，重建结果逐位一致、不再漂移，且单次重建仍在毫秒级。

**场地布局** — 直接拖动元素；0.1 m 网格吸附（`S` 开关）与边缘对齐吸附（面/中线对齐到邻近元素）；元素之间出现交叠时，视口右上角给出合并提示，可一键并入所在合并组或另建新组。

**碰撞体** — 每个合并体与松散元素各导出一个碰撞网格：`.json` 清单（边界盒、三角面数、流形状态、元素/切割体来源、OBJ 顶点区间）+ `.obj` 几何。适合作轨迹检测的输入。视口里可以打开「碰撞体」查看线框。

**导出 / 导入** — 项目文件 `.grind.json`（几何 + 布局，可再导入还原）；模型 `.stl` / `.glb`（合并后的实体）；碰撞网格 `.json` + `.obj`。导入会做校验、修复悬空引用，并拒绝不可用的文件。

**本地保存** — 编辑自动写入 `localStorage`，刷新页面后恢复场地。

### 稳定性设计

合并的正确性依赖“先重建，再布尔”：

1. 每个元素每次都由参数重新构造成实体（缓存只按参数+变换键命中）；
2. 每个合并组每次都由成员元素重新做布尔，缓存按成员的完整键命中；
3. 从不让布尔结果参与下一次布尔；
4. 缓存的渲染缓冲在交给主线程前做私有拷贝，因为 transfer 会 detach 缓冲区。

因此第 N 次与第 N+1 次合并的误差不会累积；重载项目或撤销重做后，几何逐位一致。

### 坐标约定

- manifold 是 Z-up，项目统一转成 three.js 的 Y-up；
- 元素原点在地面、占地中心，坡体朝 -Z 升高，+Z 是助跑侧；
- 合并体、导出文件、碰撞网格都使用同一套世界坐标，单位是米。
