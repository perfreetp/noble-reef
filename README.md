# 分子结构三维观察工具

基于 **TypeScript + React + Babylon.js（WebGPU 引擎）** 的分子结构三维查看器。
WebGPU 不可用时自动回退 WebGL2。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm test           # 化学数据层冒烟测试（解析器/键推断/氢键/矩阵数学）
```

浏览器要求：WebGPU 需要 Chrome / Edge 113+；其余浏览器自动使用 WebGL2。

## 功能

| 模块 | 说明 |
| --- | --- |
| 结构加载 | XYZ（含多帧）、PDB（ATOM/HETATM/CONECT）、MOL/SDF（V2000，SDF 多结构拆分）；文件无键信息时按共价半径距离判据自动推断；支持拖拽文件到视口 |
| 球棍模型 | 原子球 thin-instance 实例化；键为圆柱实例，单/双/三键用不同粗细区分 |
| 空间填充 | 按范德华半径放大球体，隐藏键 |
| 交互 | 鼠标旋转/缩放/平移（ArcRotateCamera）；点击拾取原子，高亮该原子及相邻键，面板显示元素符号、坐标与各键键长 |
| 剖切 | 可拖动的剖切平面（拖中央手柄或滑杆调节）；原子球按平面裁剪，跨平面键截断重建，截面处生成封口圆盘 |
| 氢键 | 虚线单独渲染（单条 LineSystem 手工切分 dash），按距离阈值（2.4–4.0 Å）筛选 |
| 结构列表 | 同时载入多个分子，勾选切换显示，每个分子独立配色（CPK / 自定义颜色） |
| 视图设置 | 保存配色方案、剖切平面位置、氢键与相机参数，导出 JSON 文件分享，可再导入恢复 |

## 性能设计（5 万原子场景）

- 原子/键全部使用 **thin instance**（每个分子仅几次 draw call）；
- 实例按**元素种类排序**后分批（每批 8192），同种元素连续排布，减少渲染状态切换；
- **实例缓冲分批上传 GPU**，批间让出主线程，加载大结构不卡界面；
- 键矩阵手写 TRS 组合（无临时 Matrix 对象分配），剖切拖动时经 rAF 合并逐帧重建；
- 拾取仅针对原子批次网格开启 thin-instance 拾取，键/封口/虚线不参与；
- 内置 NaCl 38³ 示例（≈5.5 万原子、8 万键）用于压测，右上角实时显示 FPS。

## 目录结构

```
src/
  chem/            化学数据层（无渲染依赖，可独立测试）
    elements.ts    元素表：CPK 颜色 / 共价半径 / 范德华半径
    parsers.ts     XYZ / PDB / MOL / SDF 解析
    bonds.ts       键推断（空间哈希）与氢键检测
    samples.ts     内置示例：苯、聚乙烯、水团簇、NaCl 晶体
  viewer/
    engine.ts      WebGPU 优先、WebGL2 回退的引擎创建
    moleculeRenderer.ts  单分子渲染器（实例化球/键、剖切封口、高亮、氢键虚线）
    clipPlane.ts   剖切平面可视化与拖拽
    controller.ts  场景/相机/拾取/多分子管理/视图设置导入导出
  App.tsx          侧栏 UI（结构列表、显示模式、氢键、剖切、视图设置）
```
