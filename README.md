# 发丝束造型编辑器

面向发型师的三维发束造型工具：在三维头模上直接摆设发束，调整参数、成组联动、检测穿插，并导出/载入发型文件。

技术栈：TypeScript + Svelte 5 + three.js（Vite 构建）。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
npm run check    # 类型检查
npm test         # 核心逻辑冒烟测试（曲线确定性/撤销重做/分组联动/文件往返）
```

## 功能与操作

| 功能 | 操作 |
| --- | --- |
| 旋转视角 / 局部放大 | 左键拖动旋转，滚轮缩放（可放到发根处检查衔接） |
| 新建发束 | 「新增发束」工具：在头皮上按下拖出方向，松手创建，根部自动锚在头皮网格上 |
| 移动发束 | 「选择/移动」工具：拖动发根手柄，整束跟随且发根始终贴住曲面 |
| 参数调整 | 右侧面板滑杆：长度 / 粗细 / 卷曲度 / 弯曲方向（另有下垂角、蓬松度）；多选或成组时按相对关系联动 |
| 梳子 | 顺着发束拖拽，影响半径内的发束方向转向拖拽方向、卷曲度降低 |
| 刷子 | 在发束上涂抹，局部增加蓬松度 |
| 成组 | 多选后「成组」，组内任一根改动其余按增量联动；可解散 |
| 穿插提示 | 自动检测发束穿插并在面板列出，选中后可上调/下调层级顺序 |
| 撤销/重做 | Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y，覆盖新建、拖动、参数、成组、删除、清空 |
| 导出/载入 | 导出 `.hairstyle.json`（含全部发束与头皮锚点），载入后分布与参数完全还原 |
| 演示发量 | 一键生成 1200 束，验证大规模编辑流畅度 |

## 架构

```
src/
  lib/hair/
    types.ts      发束/锚点/分组数据结构与参数范围
    curve.ts      参数化发束中心线（确定性：同参数必得同曲线，撤销/重载形态一致）
    geometry.ts   变截面锥形管几何（粗细影响截面，根粗梢细）
    scalp.ts      程序化头模 + 射线吸附（发根贴住曲面）
    model.ts      非响应式数据核心 + 曲线缓存 + 变更事件
    renderer.ts   分块合并 BufferGeometry（64 束/块，脏块增量重建）+ InstancedMesh 发根手柄
    history.ts    命令模式撤销/重做（快照恢复，形态完全一致）
    tools.ts      梳子/刷子笔刷逻辑（射线邻近 + 距离衰减）
    intersect.ts  空间哈希穿插检测
    io.ts         发型文件导出/解析/载入
    demo.ts       演示发量生成
  lib/state/      Svelte stores（工具、选中、组、穿插提示）与共享上下文
  components/     Viewport（three.js 场景与交互）、参数/分组/穿插面板
```

### 性能要点

- 上千发束合并为少量分块 BufferGeometry（约 64 束/块），参数变化只重建所在块；
- 发根手柄用单个 InstancedMesh，一次 draw call，拾取走 instanceId + 屏幕空间兜底；
- 曲线带缓存，仅在被修改的发束上失效重算。

### 数据格式

发型文件为 JSON（`format: "hair-strand-style", version: 1`），包含每束的锚点（头皮表面位置+法线）、
全部参数、颜色、层级与分组信息，载入后逐字段还原。
