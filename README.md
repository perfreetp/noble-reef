# 点翠冠冕 · 羽光编辑渲染工具

TypeScript + React + three.js + postprocessing 的点翠冠冕羽枝编辑与渲染工具。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建
```

## 四个模块(按制作流程)

1. **羽枝库** — 24 种翠羽条纹纹理(4 色系 × 6 纹样,程序化生成),纤维密度与丝理走向可调;单根羽枝沿脊线曲线生成片状网格,纵向最多 64 段细分,边缘列施加确定性抖动表现绒毛,并按冠面半径包覆弯曲。
2. **冠体装配** — 羽枝按参数化冠面弧度贴合;点击选中后可沿冠梁拖动、旋转(`[` `]`)、镜像(`M`);光标落在冠面上实时显示贴合法线箭头与最近羽枝间隙,间隙 > 0.4mm 标红(箭头、提示与羽片边缘红光)。
3. **羽光调校** — 核心模块。翠羽按 Kajiya-Kay 各向异性高光渲染,纤维方向角、虹彩偏移色相、光泽锐度(丝缎/亮泽/镜亮三档)逐羽枝可调;光源方位角/俯仰角连续拖动(滑杆或视口内 Alt+拖动);半透明羽片每帧按视深预排序,避免叠加闪烁。
4. **成片导出** — 离屏 2 倍分辨率渲染输出 PNG;同时可导出羽枝配置 JSON,回读后全部羽光参数(光源方位/俯仰/强度、纤维角、色相、锐度)与导出时一致。

## 性能与增量更新

- 目标:200 根羽枝 × 64 段细分下拖动光源稳定 55fps+(视口右上角实时帧率,≥55 绿色)。
- 所有羽枝材质共享同一组光照 uniform 对象,拖动光源只改一处,不触碰任何几何。
- 参数改动按类别增量重算:纹理参数只重生成该羽枝纹理;几何参数只重建该羽枝网格;放置参数只更新该羽枝矩阵;光学参数只写 uniform。冠面与其他羽枝不参与重算。
- 羽枝库面板提供「200 根 × 64 段压测」一键验证。

## 目录结构

```
src/
  engine/
    types.ts            参数类型与常量(1 单位 = 1mm,间隙阈值 0.4mm)
    crownSurface.ts     参数化冠面、法线/切线标架
    featherGeometry.ts  羽枝曲线片状网格(边缘绒毛、冠面包覆)
    featherTextures.ts  24 种条纹纹理程序化生成
    featherMaterial.ts  各向异性 + 虹彩 ShaderMaterial
    Feather.ts          单根羽枝实例(独立重建)
    CrownEngine.ts      场景/交互/排序/导入导出/渲染循环
  ui/panels.tsx         四个模块面板
  App.tsx               布局与 HUD
```
